# 2.6.3 检索策略冻结记录

固定数据集为 `scripts/fixtures/retrieval-bilingual.json`，按 LF 标准化后的 SHA256 `6de0a85f286314ba8e1f366136edd59e2aec0b9cdc97ba1562ecbe87e28f9892`（Windows CRLF 原始字节哈希为 `84c7eff40594a0357666ff245182f0ed2344e562c21728481d677e84517840f9`）。标准化只修正跨平台换行，不修改评测内容。36 条合成记忆，训练 16 个问题、留出 28 个问题；两部分主题独立，不含用户记忆。以下策略在提交 `6ba7c08` 中先于留出评测冻结；后续性能改动不调整这些参数。

选择继续使用约 25MB 的 BGE 小模型；更大的 multilingual-e5-small 候选在该训练集上未取得更好的召回/误召回平衡，不增加基础包或默认模型体积。语义训练中也比较了提高阈值及去均值，直接提高阈值会漏相关项，去均值未取得更好平衡。

修正 BGE 编码：CLS 池化、归一化、查询加检索指令，文档不加指令。符合[模型作者的编码说明](https://huggingface.co/BAAI/bge-small-zh-v1.5#usage-for-embedding-model)。内置模型相似度阈值冻结为 0.45；其他端点保留 0.35，不能混用模型分布。预处理空间改为 `transformers-feature-extraction-v2:cls:query-instruction:normalize:q8`，旧平均池化向量需要 `model reindex`，不能直接混算。

英语问题忽略常见功能词的独立命中，保留否定词、原文整句加成和仅功能词的直接检索。中文切词与精确实体过滤保持既有规则。

训练集实际混合+图谱结果：2.6.2 Recall@5 91.67%、MRR 86.11%、无关问题有结果率 50%；候选 Recall@5 91.67%、MRR 91.67%、无关问题有结果率 25%。Precision@5 固定除以 5，两者均为 25%。小型人工判断集不代表真实使用分布。

留出验收不得反过来调整此处的参数。若留出失败，记录失败而不宣称交付；任何后续调参都需要新的独立验收集。最终报告另记录留出指标、真实模型耗时与常驻 MCP 的规模性能。

CPU 采样表明重复实体匹配和查询权重查表是关键词热点。删除每条记录重复的实体切词/Set，查询权重预先展开、长度归一化每条记录仅计算一次。当前 10000 条合成 dense 向量测试：关键词冷检索从约 108ms 降至约 83ms，宽泛中文热检索 P95 从约 10.6ms 降至约 6.6ms；后续以真实磁盘/MCP 和同机基线作最终验收。
